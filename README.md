
 ## 🏥  Hospital_Emergency_Room_Dashboard

An interactive data analytics dashboard designed to analyze Hospital Emergency Room (ER) data and generate meaningful insights into patient visits, admissions, waiting times, satisfaction scores, and department referrals.

## 📊 Dashboard Preview

![Hospital Emergency Room Dashboard](Hospital%20Dashboard%20Final%20.jpg)

## 🎯 Project Objective

The objective of this project is to analyze Emergency Room data and present key performance indicators (KPIs) and visual insights that can help understand patient flow, admission patterns, waiting times, and department-wise referrals.

## ✨ Key Features

- **Patient Overview:** Total number of patients and patient visit trends.
- **Admission Analysis:** Comparison of admitted and non-admitted patients.
- **Waiting Time Analysis:** Average patient waiting time and attendance within or beyond the expected time.
- **Patient Satisfaction:** Average patient satisfaction score.
- **Gender Distribution:** Analysis of patients by gender.
- **Age Group Analysis:** Patient distribution across different age groups.
- **Department Referrals:** Insights into referrals across hospital departments.
- **Monthly Trends:** Month-wise patient visit analysis.
- **Year Selection:** Compare data across available years.

## 📈 Key Performance Indicators

The dashboard highlights the following metrics:

- Total Number of Patients
- Average Waiting Time (Minutes)
- Average Patient Satisfaction Score
- Admission Status and Admission Rate
- Patient Attendance Timeliness
- Gender and Age Group Distribution
- Department-wise Patient Referrals

## 🚀 How to Use

1. Clone or download this repository.
2. Open the project files on your computer.
3. Open the dashboard in Microsoft Excel if the Excel workbook is available.
4. Use the available year and month filters to explore patient data.
5. Review the charts and KPIs to understand admission patterns, waiting times, and department referrals.

**Note:** The repository currently contains the dataset and dashboard preview. If the original Excel workbook is not included, the interactive dashboard must be recreated in Excel using the provided dataset.
